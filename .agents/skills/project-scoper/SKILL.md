# Project Scoper

Convert a validated or chosen idea into a realistic, executable plan.

## Workflow

1. **Confirm Constraints**:
   - Ask or confirm: timeline, solo vs. team, preferred tech stack/tools, and definition of "done".
2. **Define the MVP (MoSCoW)**:
   - **Must-Have**: Absolute minimum to deliver core value.
   - **Should-Have**: Important, but can wait for v1.1.
   - **Won't-Have (for now)**: Explicit scope cuts to prevent over-engineering.
3. **Outline High-Level Architecture / Workflow**:
   - Keep it simple and pragmatic (components, data flow, key integrations).
4. **Milestone & Task Breakdown**:
   - Break work into small, concrete phases (e.g., Phase 1: Setup & Core, Phase 2: Integration, Phase 3: Polish & Launch) with checklist items.
5. **First Action**:
   - Highlight the single smallest task the user can start in the next 30 minutes.
